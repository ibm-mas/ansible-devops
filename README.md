# Ansible DevOps Collection for IBM Maximo Application Suite

## Installation
Install the collection directly from [Ansible Galaxy](https://galaxy.ansible.com/ui/repo/published/ibm/mas_devops/):

```bash
ansible-galaxy collection install ibm.mas_devops
```
