arcgis¤

Installs IBM Maximo Location Services for Esri.

This dependency is an alternative solution if you are planning to leverage geospatial and map features with Maximo Spatial. The biggest benefit of using it is that you could have both IBM Maximo Location Services for Esri and Maximo Spatial deployed and running in the same cluster, which significantly improves your overall networking performance.

Note: IBM Maximo Location Services for Esri makes use of MAS cluster issuers to manage internal and public certificates. While you are using suite_dns to set up the cluster issuer and public certificates for your MAS instances, these are automatically reused for your instance of IBM Maximo Location Services for Esri.

Installation¤

ibm_entitlement_key¤

IBM entitlement key used to authenticate access to the IBM container registry for pulling IBM Maximo Location Services for Esri images. Obtain it from the IBM Container Library.

  • Required
  • Environment Variable: IBM_ENTITLEMENT_KEY
  • Default: None

Without a valid key, the ArcGIS operator and component images cannot be pulled and installation will fail. Keep the key secure and do not commit it to version control, and verify its validity before deployment to avoid installation failures.

mas_catalog_source¤

Catalog source for the MAS operator installation — ibm-operator-catalog (default, the standard IBM operator catalog) or a custom catalog name for airgap or development environments.

  • Optional
  • Environment Variable: MAS_CATALOG_SOURCE
  • Default: ibm-operator-catalog

The default is appropriate for both release and development installations; override only when using a custom or mirrored catalog, which determines the source of operator images and available versions together with mas_arcgis_channel. For airgap installations, ensure the catalog has been properly mirrored with all required ArcGIS images.

mas_arcgis_channel¤

Subscription channel for the IBM Maximo Location Services for Esri operator — for example 9.1.x (default) or 9.0.x.

  • Optional
  • Environment Variable: MAS_ARCGIS_CHANNEL
  • Default: 9.1.x

Controls which version stream is installed and which updates are automatically applied; the 9.1.x channel receives updates within the 9.1 version stream. Changing channels may trigger upgrades or require operator restarts, so review the release notes first. Related to mas_catalog_source.

MAS Configuration¤

mas_instance_id¤

MAS instance identifier to deploy ArcGIS for — a valid MAS instance ID (lowercase alphanumeric, max 12 characters).

  • Required
  • Environment Variable: MAS_INSTANCE_ID
  • Default: None

Determines the namespace where ArcGIS is deployed (mas-<mas_instance_id>-arcgis) and which MAS instance it integrates with. The MAS instance must exist before deploying ArcGIS, and ArcGIS automatically uses the MAS cluster issuers for certificate management.

custom_labels¤

Custom labels to apply to ArcGIS instance resources, as a comma-separated list of key=value pairs — for example env=prod,team=spatial,cost-center=12345.

  • Optional
  • Environment Variable: CUSTOM_LABELS
  • Default: None

Labels must follow Kubernetes label syntax (alphanumeric, hyphens, underscores, dots). Useful for cost allocation, environment identification, resource queries, and automation scripts.
